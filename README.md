# 감정지도 · Emotion Atlas

색과 사물, 움직임으로 마음속 풍경을 그리는 로컬 저장 창작 앱.

실행: https://mcroky.github.io/emotion-atlas/

v0.13.0 웹 베타. 이 저장소는 실행용 정적 빌드만 게시합니다.
지도와 개인 메모는 브라우저의 기기 저장소에 보관하며 서버로 자동 전송하지 않습니다. 브라우저 데이터 삭제 전에는 설정의 전체 백업/복구에서 파일을 저장하세요. 백업 파일은 암호화되지 않습니다.

기존 로컬 개발 주소의 자료는 이 사이트로 자동 이동하지 않습니다. 기존 앱에서 전체 백업한 파일을 이 사이트에서 복구하면 새 사본으로 추가됩니다.
